========================================
   DVD SAITO  -  Editor de fotos  (tema Windows 98)
========================================

USAR LA APP
-----------
Doble clic en "DVD Saito.exe". No necesita instalar nada.

Al abrir sale una pantalla azul de arranque (estilo Windows NT) con los
archivos del codigo como si fueran drivers. Es una animacion; al terminar se
abre la app. Se puede saltar con un clic o cualquier tecla.

Dentro:
- Barra gris "DVD Saito" arriba, con minimizar / maximizar / cerrar.
  Arrastra la barra para mover la ventana. Maximizar respeta el monitor donde
  este. Para redimensionar, arrastra el borde derecho, el inferior o el grip
  de la esquina (los puntitos de abajo a la derecha).
- Archivo > Abrir imagen (o el boton Abrir). Tambien puedes arrastrar una
  imagen y soltarla sobre la ventana.
- En Filtros elige una categoria y toca un filtro. Cada boton muestra una
  miniatura con ese filtro sobre tu foto.
- Sliders de color, textura, Lo-Fi y proporciones.
- Aplicar efecto: fija el efecto actual y deja poner otro encima.
  Imagen > Deshacer aplicar revierte el ultimo.
- Ver original (mantener apretado) compara antes y despues.
- Archivo > Guardar como: PNG o JPG.

ESTRUCTURA DEL CODIGO
---------------------
main.py                     -> abre la app
saito/
  app.py                    -> la ventana principal
  window.py                 -> mover, redimensionar, minimizar/maximizar
  splash.py                 -> la pantalla de arranque azul
  dialogs.py                -> el dialogo Acerca de
  theme.py                  -> colores, fuentes y recursos
  assets/                   -> icono (dvd.webp) y saito.ico para el .exe
  engine/                   -> el motor de imagen
    pipeline.py             -> junta todo (process)
    filters.py              -> los filtros y sus categorias
    effects.py              -> pixelado, JPEG, halftone, etc.
    adjustments.py          -> los ajustes de color
    helpers.py              -> operaciones basicas de imagen

reconstruir.bat             -> vuelve a generar "DVD Saito.exe" tras editar

RECONSTRUIR EL .EXE
-------------------
Despues de cambiar cualquier archivo dentro de saito, corre "reconstruir.bat"
y se genera un nuevo "DVD Saito.exe".
